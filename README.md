## Hi, I'm Jaswanth Krishna Kondisetty

I'm currently an ERP Coordinator at Vintech Industries in Michigan, working with Plex ERP in an automotive manufacturing environment. Day to day I write SQL queries in the Plex SQL environment to pull production and inventory data, build Power BI dashboards for operations reporting, and help keep the ERP running cleanly across departments.

Before this role I spent a year as a Data System Analyst at Efftronics in India, building Python/SQL monitoring pipelines and automated reporting that cut manual reporting time by 30-40%.

I did my Master's in Computer Science at Lawrence Technological University (2024-2025), where most of my project work was around NLP and computer vision.
